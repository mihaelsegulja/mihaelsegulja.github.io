Microclimate IoT System

College Final Project

C++ * ESP32 * ASP.NET Core * Angular * SQL Server * RabbitMQ * MQTT * SignalR
[source code ->]

An ESP32 collects indoor temperature, humidity, pressure, CO2, and air quality readings and sends them through MQTT and RabbitMQ. The flexible message format makes measurements easy to add or remove, while two-way communication separates device telemetry from commands sent back to devices. A .NET 8 backend stores the telemetry in SQL Server and streams live updates with SignalR. The Angular dashboard provides live and historical charts, room and device management, and configurable alert rules.
