# mihaelsegulja.github.io

[![Deploy to GitHub Pages](https://github.com/mihaelsegulja/mihaelsegulja.github.io/actions/workflows/gh-pages-deploy.yml/badge.svg)](https://github.com/mihaelsegulja/mihaelsegulja.github.io/actions/workflows/gh-pages-deploy.yml)

Personal website showcasing my projects, skills, and background as a software engineer.

## Live site

[https://mihaelsegulja.github.io](https://mihaelsegulja.github.io)

## Tech stack

- Astro
- TypeScript
- CSS
- GitHub Pages
- GitHub Actions

## Development

Requires Node.js 22.12.0 or newer.

```sh
npm ci
npm run dev
```

Build and verify the static site with:

```sh
npm run build
npm test
```

## Deployment

Deployment to GitHub Pages is handled automatically by GitHub Actions on pushes to `main`.
