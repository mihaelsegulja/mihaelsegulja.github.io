Marx Weather Station ->

An IoT project for monitoring air quality, temperature and more using an ESP32 and BME680 sensor. It collects sensor data, sends it via MQTT to a backend service, stores it in a SQL Server database, and visualizes data for a given time period.

C# * ASP.NET * SQL Server * ESP32 * MQTT * RabbitMQ * HTML * CSS * JavaScript
